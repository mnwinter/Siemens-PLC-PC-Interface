# Codex handoff

The durable AI/contributor context for this repository is versioned here:

- [`AGENTS.md`](AGENTS.md) — contributor and AI operating rules;
- [`docs/AI_HANDOFF.md`](docs/AI_HANDOFF.md) — architecture, history, current
  implementation boundary, live-PLC path, user acceptance requirements, and
  reproducible verification commands;
- [`CONTEXT.md`](CONTEXT.md) — domain glossary and runtime ownership rules;
- [`PROJECT_INFORMATION.md`](PROJECT_INFORMATION.md) — chronological project
  evidence and prior decisions;
- [`README.md`](README.md) — product usage and setup;
- [`rungproof-next/README.md`](rungproof-next/README.md) — Godot Next scope and
  offline virtual-controller contract.

Machine-local Codex transcripts, caches, credentials, and temporary session
artifacts are intentionally not copied into Git. They are not portable project
source and may contain private user data. This handoff contains the actionable
background needed by another AI without those risks.
